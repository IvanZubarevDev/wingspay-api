Page vs. endpoint

This is an ordinary web page 404 — you followed a link or typed a URL for a page that doesn't exist on api.wingspay.net (the human-facing site, not the API itself).

If you're integrating and called a REST endpoint under /v1/ that doesn't exist, you get a different, real JSON 404 response like the one shown above — not this HTML page. See the API Reference for every valid /v1/ route.
