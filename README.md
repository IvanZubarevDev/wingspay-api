# wingspay-api

The WingsPay API host — served at `https://api.wingspay.net/`.

Satellite repository — no local engineering documentation; this repo follows `wingspay-site`'s. Stage 1 status: a static Developer Preview, not a real backend.

## Engineering documentation

Architecture, endpoint reference, and forward-compatibility contract
for this repository live in
`wingspay-site/engineering/architecture/API_FUTURE_VISION.md` — start
there for anything beyond "what is this repo." Platform-wide process
documentation (QA, design system, migration history) lives in the
`wingspay-site` repository's `engineering/` folder.
